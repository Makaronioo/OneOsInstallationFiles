# OneOS Installation Files

Repozytorium służy do udostępniania plików potrzebnych do instalacji **OneOS**. Pliki do pobrania będą publikowane w sekcji [Releases](https://github.com/Makaronioo/OneOsInstallationFiles/releases) — sprawdź opis danego wydania, aby zobaczyć jego zawartość i wymagania.

## Pobieranie

1. Otwórz [najnowsze wydanie](https://github.com/Makaronioo/OneOsInstallationFiles/releases/latest).
2. Pobierz wymagany plik z sekcji **Assets**.
3. Przed użyciem zapoznaj się z instrukcją i ostrzeżeniami w wydaniu oraz w głównym repozytorium OneOS.

## Powiązane projekty

- [OneOS](https://github.com/fahadalijaved/OneOS) — główny projekt i instrukcje.
- [KernelSU](https://github.com/tiann/KernelSU) — rozwiązanie root dla Androida; wymagania dotyczące root sprawdź w dokumentacji OneOS.

> **Uwaga:** OneOS jest projektem eksperymentalnym. Instalacja lub użycie niezgodnych plików może spowodować utratę danych albo problemy z urządzeniem. Wykonaj kopię zapasową i korzystaj wyłącznie z plików przeznaczonych dla Twojego modelu telefonu.
